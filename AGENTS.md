# Инструкции для Codex

Эти инструкции применяются ко всем будущим задачам Codex в репозитории
`GItShiha/motivation-app` и ко всему его дереву файлов.

## Авторство Git-коммитов

1. Перед созданием любого коммита в этом репозитории устанавливай локальную
   Git-конфигурацию, выполняя команды из корня репозитория:

   ```bash
   git config --local user.name "GItShiha"
   git config --local user.email "GitHubShiha@proton.me"
   ```

2. Перед каждым коммитом проверяй эффективные значения:

   ```bash
   git config user.name
   git config user.email
   ```

   Продолжай создание коммита только если значения точно равны `GItShiha`
   и `GitHubShiha@proton.me`. Не переопределяй их другим автором через
   параметры команды или переменные окружения.

3. Не используй для авторства коммитов имя `Egoshiha Capac` и почту
   `egoshaofpoker02@gmail.com`.
4. Не изменяй глобальные настройки Git. Настройка авторства должна оставаться
   локальной для этого репозитория.
5. Не переписывай историю существующих коммитов, в том числе ради изменения
   их авторства.
